# ADR-001: Independent reimplementation

- Status: Accepted
- Date: 2026-08-29

## Decision

Build an independent PHP-specific implementation inspired by [JetBrains/go-modern-guidelines](https://github.com/JetBrains/go-modern-guidelines). Do not represent it as an official JetBrains port.

## Consequences

The project may use a PHP-specific model and wording while retaining clear attribution and an Apache-2.0 project license. M0 copies no upstream source files; any future copying or modification requires a new notice review.
