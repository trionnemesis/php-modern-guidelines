# ADR-002: Narrow product boundary

- Status: Accepted
- Date: 2026-08-29

## Decision

The core concerns versioned PHP language, Core, and bundled-extension guidance. It does not prescribe architecture or framework practices, analyze target code, or apply automatic changes.

## Consequences

The project remains distinct from broader projects such as [netresearch/php-modernization-skill](https://github.com/netresearch/php-modernization-skill). Framework packs and verification adapters require later, isolated decisions.
