PHP 8.2+ · M0 foundation

Modern PHP guidance that respects the whole version range.

A foundation for coding agents to consult declared PHP compatibility policy before they write code—not a framework modernizer, analyzer, or auto-fixer.

Foundation / alpha v0.0.1

CLI skeleton and schemas are available. Policy resolution and guidance are planned next.

The point

Two axes, one honest policy.

01

Feature ceiling

The lowest allowed PHP minor. Generated syntax must run across the project’s declared range.

02

Lifecycle ceiling

The highest known allowed minor. Newer deprecations and removals still matter.

For a future policy such as ^8.2, the two ceilings are intentionally not collapsed into one runtime value.

M0 status

A deliberately small foundation.

Available now

  • php-modern-guidelines version
  • Rule and policy JSON Schema contracts
  • PHP 8.2–8.5 CI configuration

Planned next

  • Composer Semver policy resolver
  • Read-only resolve, list, and explain
  • Official-source rule registry

Not M0

  • PHP modernization rules
  • Framework packs and analyzers
  • Auto-fixing or marketplace manifests

Trust boundary

Designed to advise, not to act on your project.

Future core commands are intended to be deterministic and read-only: no target PHP execution, no analyzed-project vendor/autoload.php, no Composer scripts or plugins, no network access, and no writes to the analyzed repository.

This is an independent implementation inspired by JetBrains/go-modern-guidelines. It is not affiliated with or endorsed by JetBrains. Its narrow planned scope is distinct from netresearch/php-modernization-skill.
